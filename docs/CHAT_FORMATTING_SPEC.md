# POYOZZ 聊天排版最終規格（鎖定）

本規格適用於單人與群組聊天室，兩者共用同一套訊息呈現規則。

## 文字換行

1. **單星號包覆的旁白／動作**（例如 `*他停下腳步，回頭看你*`）：桌面版維持約 25 個全形中文字的最大行寬；手機版不再固定字數或 25em，而是自適應聊天室面板可用寬度，左右各距離面板邊框 1px。角色旁白靠左，玩家旁白靠右。
2. **一般角色對話氣泡**：維持每行約 18 個全形中文字。氣泡內距必須納入計算；外框約 `20em`，扣除左右 padding 後約可容納 18 個全形中文字。
3. 只有單星號旁白／動作可在手機版延伸至面板寬度；一般對話氣泡不可跟著滿版，兩者必須使用不同寬度規則。
4. 單人、群組共用同一套規則。調整訊息元件、字體、padding 或 line-height 時，必須同時跑 `test-story-phone-and-suggestions-regression.mjs` 驗證。

## 變更管制

- 手機版旁白距面板左右邊框各 1px；不可讓旁白溢出面板或覆蓋對話氣泡。
- 一般對話維持 18 字換行，不得因旁白自適應而改成滿版。
- 程式碼瘦身只可移除重複實作，不得改變可見換行結果。
