# POYOZZ 聊天排版最終規格（鎖定）

本規格適用於單人與群組聊天室，兩者共用同一套訊息呈現規則。這是已確認的最終需求；後續 UI、CSS、效能瘦身、元件重構及手機版調整不得自行改動。

## 文字換行

1. **單星號包覆的旁白／動作**（例如 `*他停下腳步，回頭看你*`）：每行以 **22–24 個全形中文字**為目標再換行。旁白使用獨立的較寬版面，CSS 上限為約 `24em`。
2. **一般角色對話氣泡**：每行以 **18 個全形中文字**為目標再換行。氣泡內距必須納入計算，不能只看外框寬度；目前外框約 `20em`，讓扣除左右 padding 後的文字區約可容納 18 個全形中文字。
3. 旁白與對話氣泡必須使用不同寬度規則，不可共用一個寬度，也不可將兩者改成滿版。
4. 手機版必須保留相同字數規格，不可用 media query 將旁白或對話氣泡強制改成 `width:100%`。
5. 單人、群組都必須遵守；調整訊息元件、字體、padding 或 line-height 時，必須同時跑 `test-story-phone-and-suggestions-regression.mjs` 驗證。

## 變更管制

- 除非使用者明確提出新的換行規格，否則不得修改以上字數與寬度目標。
- 程式碼瘦身只可移除重複實作，不得改變可見換行結果。
- PR 說明、CSS 註解與回歸測試必須保留這條規格。
